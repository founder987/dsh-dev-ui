## 实现差异说明（验收 1）

产品概述布局（v1.0）规划"文件内容入 details 列（`ctx.layout` 开关）"。实际实现中：
- **details 槽为 single**，被官方工具详情（`conversation.details.tool`）占据；替换会导致工具详情功能丢失
- 当前方案：**文件内容在文件树面板内**（面板下部内容区），对话仍为中列官方 UI
- 影响：布局与产品概述 ASCII 图不完全一致，但功能闭环完整

**决策**：保持面板内内容区（不替换 details 槽）；产品概述已标注差异。若后续需要 details 列承载文件内容，需先解决与工具详情的共存（如 details 槽分区或自定义列）。
