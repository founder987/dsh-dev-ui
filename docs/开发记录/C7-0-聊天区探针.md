## 关键源码事实

### ① 数据管线（root 域 → 会话快照）

```
ctx.sessions                    // SessionRuntime（runtime client.js provide("sessions")）
  .list                         // 快照 store：{ ids, byId, current, ... }，.subscribe/.getSnapshot
  .manager.sessions             // Map<sessionId, Session>（公开字段）
    .get(id).subscribe(fn)      // Notifier 订阅
    .getSnapshot()              // { chat: { nodes: Map, legacy }, running, promptError, ... }
```

官方 useSession 选择器实证：`s.chat.nodes.get(nodeKey)`、`s.chat.legacy.nodes`（conversation client.js L2811/L3364/L5239）。

### ② 节点形状（conversation client.js L7246 `chatNode` + L8199 messageDefinition）

- user 消息（含 steering 中途引导）kind ∈ `'user' | 'steering'`，`data.content` 为 string
- 取「当前提问」= 可见节点中 kind 匹配且 `data.seq` 最大者；历史队列 = 升序全量 + 连续去重
- 守卫：`visibility === 'visible'`、`typeof data.content === 'string'`

### ③ ↑↓ 仲裁（conversation client.js L3506-3509、L1052）

```js
// 官方 InputBar onKeyDown
if (e.key === "ArrowUp" || e.key === "ArrowDown") {
  if (keyboard.arbitrate(dir, composing) === "consumed") e.preventDefault();
  return; // pass 时不 preventDefault → 默认光标移动
}
```

**避让方案**：R10 监听挂 **bubble 阶段**（官方 handler 之后执行），先查 `e.defaultPrevented`：
- `defaultPrevented === true` → 官方弹层消费了（命令/提及菜单导航）→ 完全放行
- 否则再按交互设计条件（草稿空 / 光标首行 / 回显中）决定是否 `preventDefault` 接管

### ④ composer DOM 定位

- composer 容器标记：`[data-composer-seat]`（client.js L6937）
- R10 锚点：`conversation.input.left` 槽组件渲染 0 宽占位 span（0 宽保挂载先例），`closest('[data-composer-seat]')` → `querySelector('textarea')`

## 勘误（2026-08-26 真机失效根因）

本文 ② 记录的两处类型层形状与运行期实现不符（真机 CDP 实证，双双导致
R9 浮层与 R10 回显失效）：

1. `chat.nodes: Map` → 运行期是 ui-conversation 的 `MutableChatNodeStore`
   （普通 class，仅 get/values/replace/upsert，非 Map 实例）。`instanceof Map`
   守卫误判为空队列。已修为 values 鸭式判定（测试 A5）。
2. `data.content 为 string` → 运行期是 `ContentBlock[]`（`[{type:'text', text}]`，
   可含 image 等非文本块）。`typeof content !== 'string'` 守卫过滤掉全部用户
   节点。已修为 contentToText 拼接 text 块（测试 A6）。

验证方式：Electron `--remote-debugging-port=9222` + CDP Runtime.evaluate
（React fiber 扫描会话快照 / AskFloat uSES 状态），工具脚本在 .apicheck/cdp-*.mjs。

## R9 v2 滚动跟随（2026-08-27）

浮层内容由「恒显最新提问」改为「跟随可视区第一行所属提问」：

- askFeed 快照新增 `entries: { key, text }[]`（seq 升序、不去重、含节点 key，
  key 与 DOM `[data-chat-flow-key]` 逐字一致）；`questions` 仍连续去重供回显。
- AskFloat 监听聊天列**捕获阶段** scroll（scroll 不冒泡），以浮层底边为可视区
  上沿，二分找第一可见行，纯函数 `pickQuestionAtScroll(entries, rowKeys, first)`
  取该行或其上方最近提问行；上方无提问行 → null（调用方回退第一条）；无滚动
  信息 → 跟随最新。
- 真机 4 采样点验证（scrollTop=0 / 2600 / 4500 / 7470 底部）全部命中对应提问；
  ↑↓ 回显回归通过（↑×2 取倒数第二条、↓ 回最新）。
- 坑：CDP 验证时若窗口被遮挡/最小化，`visibilityState=hidden` 导致 scroll 事件
  与 rAF 均不派发（表现为“功能没生效”）。需 ShowWindowAsync(SW_RESTORE) +
  SetForegroundWindow 置前（.apicheck/foreground.ps1），或启动参数加
  `--disable-backgrounding-occluded-windows`。
