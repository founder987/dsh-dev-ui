# 功能实现完成报告：命令白名单

> 日期：2026-08-31 ｜ 状态：✅ 编码完成（W0–W5），真机验证待执行 ｜ 依据：`specs/features/命令白名单-任务规划.md` v1.2

## Spike 结论（W0，已回写技术方案 §4）

| 项 | 结论 |
|----|------|
| S-1 匹配优先级 | `conversation.composer` 为 chain 槽，按 priority 升序评估；官方 ApprovalPanel 条目 priority 1，本条目默认 0 → 先于官方评估，selector 命中即接管，非 shell 类返回 null 交官方面板，天然共存 |
| S-2 回落 | composer chain 使用 `overlay: true`：接管时 InputBar display:none 隐藏（DOM/草稿存活）；代答后 approval 移除 → selector 落选 → InputBar 自动恢复，无需回落占位 |
| S-3 应答通道 | 包入口未导出 `PendingApproval`/`commandOf`；`PendingWait` 自 runtime 导出；应答编码照抄 client.js（`respond({ok:true,value:{sessionId,approvalId,outcome}})`）；`conversationContextKey` 自实现（`${kind.length}:${kind}${id}`，runtime client 为 __ModuleLoader__ 包装无法 node import） |
| S-4 useSession | 官方同款：组件内 `props.useSession` 查配对 call；selector 内用 `props.session` 纯函数判定 shell 类（decline 决策必须在 selector） |
