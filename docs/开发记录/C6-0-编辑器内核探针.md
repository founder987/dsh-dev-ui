## 关键事实

1. **版本锁定 `monaco-editor@0.52.2`**。0.56 不可用：basic-languages 只剩 css/html/json/ts 四种，且其 exports map `"./*": "./esm/vs/*.js"` 会导致 `esm/vs/...` 前缀双拼路径解析失败。0.52.2 无 exports map，子路径必须写全 `monaco-editor/esm/vs/...`。
2. **codicon 需显式 import**：`editor.api` 不会拉入 codicon 字体样式，必须额外 `import 'monaco-editor/esm/vs/base/browser/ui/codicons/codiconStyles.js'`，否则查找/折叠等 widget 图标缺失。
3. **JSON 无 monarch 高亮**：0.52.2 的 json 在 `language/json`（worker 版语言服务），import 会引入 worker 依赖，已放弃。JSON 文件以 plaintext 兜底（仅无语法高亮，编辑/查找/多光标不受影响）。
4. **worker 方案**：webview 中 blob worker 未验证，采用 `self.MonacoEnvironment = { getWorker: () => 空 blob Worker }` dummy stub。依赖 worker 的语言服务特性静默退化；编辑、monarch 高亮、查找替换、多光标、括号匹配全部在主线程运行。
5. **css-inject 插件**：esbuild `onLoad` 拦截 `.css`，转为运行时 `<style>` 注入（`data-plugin-css` 去重），并把 `url(...)` 引用的字体/图片读为 base64 data URI 内联，保证单文件 bundle 无外部资源请求。
6. **必须动态 import**：monaco 模块体积 2.6MB，若顶层 import 会在插件 factory 执行时同步初始化，拖慢 DSH 启动。`editorHost` 用动态 import 缓存，首次打开文件时才加载。
