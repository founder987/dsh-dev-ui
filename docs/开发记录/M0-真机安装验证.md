## 2. 安装步骤（手动本地安装，约 2 分钟）

```powershell
# ① 进入 DSH desktop profile 目录
cd C:\Users\User\.dsh\profiles\desktop

# ② 安装插件包（dependencies 一并装入 profile node_modules）
pnpm add "E:\trae-file\deepseek-harness-client\dsk-develop-ui-0.1.0.tgz"

# ③ 把插件加入 profile bundle 声明
# 编辑 C:\Users\User\.dsh\profiles\desktop\package.json，
# dsh.profile.bundles 数组追加 "dsk-develop-ui"：
#   "dsh": { "profile": { "bundles": ["@deepseek-ai/dsh-base", "@deepseek-ai/dsh-web-app", "dsk-develop-ui"] } }
```

> 说明：profile 的 `pnpm-workspace.yaml` 为 `nodeLinker: hoisted` + `autoInstallPeers: false`；
> 插件 peerDeps（react、`@deepseek-ai/*`）已在 profile node_modules（DSH 运行时依赖），无需重复安装；
> `dependencies`（markdown-it、markdown-it-task-lists、shiki）由 `pnpm add` 自动装入。

## 5. 常见问题

| 现象 | 原因与处理 |
|------|-----------|
| 日志无 host 半日志 | bundle 未声明：检查 profile package.json 的 `dsh.profile.bundles` 是否含 `dsk-develop-ui` |
| `client bundle not found` | `lib/client.js` 缺失：重跑 `pnpm run build` 后重新 `pnpm pack` |
| bundle 加载语法错误 | client.js 非 `__ModuleLoader__` 格式：确认 build.mjs 的 banner/footer 包装生效 |
| GUI 无 client 日志 | 浏览器需硬刷新（Ctrl+Shift+R）；或 `dsh.client.inject` 依赖图未满足 |
| 端口 404 | GUI 端口是动态分配的：`netstat -ano | Select-String LISTENING` 取实际端口（本机曾见 54179/49606/54262/58493） |
| `service "X" has been registered` 启动失败 | **根因（2026-08-21）**：cordis `Service` 构造自动 `ctx.provide(name, this)`，apply 里再显式 `ctx.provide` 同名服务 → 双重注册冲突。修复：apply 只 `new XxxService(ctx)`，不显式 provide（见 `tests/repro/double-load.test.mjs` 本地复现） |
