# 命令白名单 · 需求澄清

> 依据：用户变更诉求（聊天中 workspace-write 权限的命令粒度放行）｜ 文档版本：v1.1 ｜ 状态：决策点已确认（2026-08-31），可进入实施

## 背景与问题

DSH 聊天在 workspace-write 模式下，agent 执行 shell 命令需用户逐条确认。高频安全命令（如 `npm install`、`pnpm build`）逐条点「允许」体验差，用户希望：

1. 部分命令**默认放行**（白名单命中即自动允许）；
2. 未命中白名单的命令弹确认，提供三选一：**拒绝 / 允许一次 / 永远允许**（后者把该命令加入白名单）。

## 关键协议约束（可行性结论）

- 审批线上结局**只有两种**：`allowed-once` / `rejected`（`PendingApproval.answer`，dsh-client-ui-conversation `contract/slots.d.ts`）。**不存在"永远允许"的线上语义**。
- 因此「永远允许」= **插件侧持久化白名单 + 命中时代答 `allowed-once`**。host 侧审计、会话记录不变。
- 接管点：`conversation.composer` 为 `kind: 'chain'` 槽，条目按 selector 路由、命中即替换默认 InputBar（官方 ApprovalPanel 本身就是链上一条目）。插件注册自己的链条目即可接管 shell 命令类审批。

## 用户流程

```
agent 请求执行 shell 命令
  → 插件链条目 selector 命中（pending approval 且为 shell 命令类）
    → 白名单命中？—— 自动代答 allowed-once（无 UI，用户可在消息流看到已放行）
    → 未命中 —— 渲染三键审批面板：
         [拒绝]        → answer('rejected')
         [允许一次]    → answer('allowed-once')
         [永远允许 ▾]  → 展开粒度候选（按当前命令自动生成）
              · 命令名（第 1 个 token）：如 mvn
              · 子命令前缀（前 N 个 token，N 可调）：如 mvn clean package
              · 整行精确（全部 token）：如 mvn clean package -D maven.test.skip=true
          → 选择一项 → 按该粒度写入白名单 + answer('allowed-once')
  → 非 shell 命令类 approval（如文件写入）→ selector 不命中，官方面板照常
```

## 功能范围

| 项 | 范围 |
|----|------|
| 拦截对象 | 仅 **shell 命令类** approval（配对 tool call 为 bash/cmd/powershell 族、args 含 `command`）；其他 approval 走官方面板 |
| 白名单存储 | localStorage（client 侧，key `dsh-develop-ui.cmdWhitelist`） |
| 白名单管理 | 底部菜单栏 ⚙ 入口：列表 / 删除 / 手动添加 / 模式切换 |
| 匹配模式 | 统一为「前缀 token 匹配」，粒度可配置：① 命令名（token 数=1，如 `mvn` 命中所有 `mvn …`）；② 子命令前缀（token 数=N，如 `mvn clean package` 命中 `mvn clean package -D …`，不命中 `mvn clean install`）；③ 整行精确（token 数=全部，整行规范化后逐 token 相等）。永远允许时按当前命令自动生成候选，用户选粒度 |
| 作用域 | 全局（跨会话/工作区共享） |

## 验收标准

- [ ] 白名单内命令的 approval 无弹窗自动放行，消息流可见放行结果
- [ ] 白名单外 shell 命令弹出三键面板，三个按钮行为各自正确
- [ ] 「永远允许」展开粒度候选：命令名 / 子命令前缀（N 可调）/ 整行精确，选粒度后按该粒度入库并应答
- [ ] 前缀匹配语义正确：`mvn clean package` 命中 `mvn clean package -D maven.test.skip=true`、不命中 `mvn clean install`；`mvn` 命中 `mvn clean package`、不命中 `mvnx`（token 边界对齐）
- [ ] 「永远允许」后同命令（同粒度前缀）再次触发不再弹窗
- [ ] 非 shell 类 approval 不受本功能影响（官方面板照常）
- [ ] 白名单管理浮层可增删查、可手动添加（命令 + 粒度）、可清空，重启后持久
- [ ] 拒绝/允许一次不产生白名单副作用

## 决策结论（2026-08-31 用户确认）

| # | 决策点 | 结论 |
|---|--------|------|
| 1 | 匹配粒度 | **多策略可选**：永远允许时按当前命令生成多档候选（命令名 / 子命令前缀 / 整行），用户选择入库粒度。例：`mvn clean package -D maven.test.skip=true` 可选 `mvn` 或 `mvn clean package`（或整行）。命令名/子命令前缀风险标注保留 |
| 2 | 作用域 | **全局**（跨会话/工作区共享，MVP 不按工作区隔离） |
| 3 | 拦截范围 | **仅 shell 命令类** approval 走三键面板，其余走官方面板 |

> 注：`npm run <script>`、`npx`、`mvn clean package` 等可间接执行任意代码——命令名/子命令前缀粒度在面板与管理浮层均以警示色标注，默认推荐整行精确。
