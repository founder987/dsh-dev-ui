# 目标规划中心 · 需求文档

> 依据：用户澄清（2026-09-16，三轮：① 初始三条诉求 → ② 追加「路线图与资料要打包」→ ③ 泛化为任意目标）｜ 文档版本：v1.0 ｜ 状态：待确认决策点 E1–E6

## 功能概述

**所属模块**：目标规划（新增板块）  **优先级**：P1

**一句话**：你告诉它「我想做什么」，它先**识别你的意图**、**问你几个关键问题**，然后输出一份定制化的**规划包**——包含路线图与配套资料，按意图类型附带对应的准备材料（如求职类的简历建议、复习资料），最终以**可点击的 HTML** 交付。

> **定位澄清（2026-09-16 第三轮）**：用户明确「AI 转型只是一个举例」。
> 本功能是**通用目标规划器**，不绑定任何单一领域。AI 转型、换岗架构师只是两个示例。

**两个基准例子（须同时成立）**：

| 例子 | 用户说 | 期望输出 |
|------|--------|----------|
| 例 1 | "我想换个工作，目标是架构师岗位" | 识别为**求职准备** → 提问（目标公司/当前职级/时间窗口/薄弱环节）→ 输出**准备工作包**：简历优化建议 + 技能差距分析 + 复习路线图 + 复习资料 |
| 例 2 | "我想转型，目标 AI 大模型应用" | 识别为**技能转型** → 提问（现有基础/可投入时间/目标岗位/期限）→ 输出**转型工作包**：学习路线图 + 学习资料 + 实战项目 |

## 意图类型与交付物矩阵（核心设计）

意图类型由系统识别（开放式目标无法穷举，故以「默认基线 + 可扩展」处理）。基线如下：

| 意图类型 | 识别信号示例 | 澄清问题重点 | 默认交付物 |
|----------|--------------|--------------|------------|
| **求职准备** | "想换工作""面试""岗位""跳槽" | 目标岗位与职级、当前经验、目标公司类型、时间窗口、最担心的环节 | 简历优化建议 + 技能差距分析 + 复习路线图 + 复习资料 + 面试高频考点 |
| **技能转型** | "想转型""从 X 转 Y""转行" | 现有技术栈与年限、可投入时间、目标方向、期限、希望达到的程度 | 学习路线图 + 学习资料（文档/视频）+ 实战项目 + 阶段里程碑 |
| **能力提升** | "想补齐""想学""想深入" | 当前水平、应用场景、期望深度 | 提升路线图 + 资料 + 练习建议 |
| **项目实践** | "想做一个 XX 系统" | 技术栈偏好、可投入时间、验收标准 | 实施步骤 + 技术选型建议 + 参考资料 + 里程碑 |
| **认证考试** | "想考 XX 认证" | 考试时间、现有基础 | 备考路线 + 考纲拆解 + 资料 |
| **开放式其他** | 不匹配以上 | 由系统自行决定 | 由系统自行决定（输出仍走统一卡片结构） |

> 关键：**意图类型决定「问什么」和「给什么」**。这是本功能区别于普通"生成一段学习计划"的核心。

## 交付物：规划包（HTML）

最终产物是一个**自包含的 HTML 规划包**，在浏览器或 DSH 内打开即可用，**所有资料入口可点击直达**（视频跳视频、文档跳文档）。

**HTML 内容结构**：

| 区块 | 内容 |
|------|------|
| ① 目标与画像 | 你的目标原文、识别出的意图类型、你的现状画像（已具备 / 待补齐） |
| ② 路线图 | 分阶段（目标 / 关键内容 / 预计周期 / 里程碑产出物），带进度勾选 |
| ③ 资料区 | 按阶段归类的资料卡：类型（文档/视频/论文/课程）、可点击链接、难度、预计投入时长、**为什么学**、建议顺序 |
| ④ 实战/练习 | 与阶段配套的实战项目或练习题（含仓库链接、上手建议） |
| ⑤ 意图专属区块 | 求职类 → 简历优化建议、高频考点、技能差距表；转型类 → 转型要点、避坑提示 |
| ⑥ 速查索引 | 按知识点聚合资料，便于快速定位 |

**交付形态**：单个自包含 HTML 文件（内嵌样式与全部内容，零外部依赖，便于复制/分享/打印）；可选同时导出一份 markdown（见 E6）。

## 使用场景

用户是一名在职开发者，在 DSH 里工作的同时会不断产生「我想做什么」的念头——想换工作、想转型、想补齐某块能力、想做个东西。当前的做法是去搜索引擎和各类博客找"XX 学习路线"，拿到的是泛泛清单：不结合自己的现状、不给配套资料、也不知道先做哪一步，收藏完就搁置了。

**期望**：用大白话说出目标 → 被问几个真正关键的问题 → 拿到一份「当下就能照着做」的规划包，里面有路线、有资料、有可点击的链接，还能标记进度。

**使用时机**：产生新目标的当下（几分钟出结果）；之后按周回顾进度、更新画像、重新生成。

## 用户流程

### 流程 A｜提出目标与意图识别

打开目标规划中心 → 在输入框用大白话描述目标（例："我想换个工作，目标是架构师岗位"）→ 系统识别意图类型，并明确回显"我理解你想要的是：求职准备（架构师方向）"，**给用户一次纠正机会** → 同时展示本次要问的问题清单与将输出的交付物类型（让用户预期明确）。

### 流程 B｜回答澄清问题

系统按意图类型生成 5–8 个关键问题（每题给选项/示例，能选就不让打字，可跳过任意题）→ 用户作答 → 系统汇总成"现状画像"回显确认。

> 补充信息项（可跳过）：每周可投入时间、期望达成期限、偏好的学习方式（视频优先 / 文档优先）、目标公司或行业。

### 流程 C｜生成与查看规划包

点「生成规划包」→ 展示生成进度 → 完成后自动打开规划包 HTML（DSH 内预览）→ 用户在页内浏览路线图、点开资料卡链接、勾选进度。

### 流程 D｜迭代调整

对结果不满意时，回到中心用大白话补充要求（例："资料再偏实战一点""时间从 3 个月改到半年""我不需要数学那部分"）→ 重新生成 → 新版本覆盖旧版本（保留上一版备份）。

## 功能需求

### MVP 必需

- [ ] 目标规划中心入口（一处进入，可随时关闭并恢复原视图）
- [ ] 目标输入：大白话描述，支持修改重提
- [ ] 意图识别：识别意图类型并回显确认，允许用户手动纠正类型
- [ ] 动态澄清提问：按意图类型生成针对性问题，支持选项作答与跳过
- [ ] 现状画像生成与回显确认
- [ ] 规划包生成：按意图类型产出对应交付物（见交付物矩阵）
- [ ] **规划包以 HTML 交付**：自包含、样式完整、内容分区块呈现
- [ ] **资料卡全部可点击**：点击直达视频页/文档页；链接同时以纯文本展示便于复制
- [ ] 资料卡含：类型、难度、预计投入时长、为什么学、建议顺序
- [ ] 进度勾选（已学 / 未学），本地保留
- [ ] 重新生成与迭代调整（保留上一版备份）
- [ ] 生成结果落盘到工作区，可在 DSH 文件树中查看与再打开

### 后续迭代

- [ ] 资料池更新后提示「你的规划包有 X 条资料可更新」
- [ ] 规划包支持多人分享（导出为可分享的只读页面）
- [ ] 与 DSH 对话联动：把规划包作为上下文交给 agent，边做边问
- [ ] 按目标 JD 自动比对能力差距
- [ ] 进度周报与提醒

| 元素 | 类型 | 说明 |
|------|------|------|
| 入口 | 图标按钮 | 现有底部菜单栏（与 📁 📝 💬 >_ ⚙ 同排）新增一个 | 
| 容器 | 浮层卡片 | 与现有白名单浮层同模式，不挤压五列布局 |
| 步骤条 | 三步指示 | ① 说目标 → ② 答问题 → ③ 拿规划包 |
| 目标输入 | 多行文本框 + 示例提示 | 提供 3–5 个示例目标可一键填入 |
| 意图确认 | 卡片 + 「纠正」入口 | 明确回显"我理解你要的是 X"，可改类型 |
| 问题列表 | 逐题作答 | 选项优先，可跳过；显示剩余题数 |
| 画像确认 | 分层列表 | 已具备 / 待补齐，可手动修改 |

| 结果区 | 打开规划包 / 重新生成 / 补充要求 | 生成后可一键打开 HTML |
| 历史规划 | 列表 | 过往目标与其规划包，可再次打开 |

## 边界条件

| 场景 | 处理方式 |
|------|----------|
| 目标描述过于笼统（如"我想变强"） | 追问一轮以收敛；仍无法定类型则按「开放式其他」处理，并说明不确定之处 |
| 目标超出可规划范围（如"我想中彩票"） | 坦诚说明无法规划，并建议可规划的相关目标 |
| 用户跳过全部澄清问题 | 允许生成，但标注「基于通用假设，补充信息可显著提升准确度」 |
| 生成过程中断 / 失败 | 保留已答问题与画像，可重试；已生成部分不丢失 |
| 生成的资料链接失效 | 页面标注链接可复制；提供「报告失效链接」与重新生成入口 |
| 生成内容出现明显不实资料 | 资料卡标注来源，并提供人工修正入口（本地可编辑覆盖） |
| 工作区无写权限 | 提示并提供「下载 / 复制 HTML」兜底 |
| 已有同目标的规划包 | 提示「已有该目标的规划包」，可选覆盖 / 另存为新版本 |
| 同时存在多个目标 | 支持多个规划并行保存，互不覆盖 |

## 验收标准

- [ ] 例 1（"我想换个工作，目标是架构师岗位"）能识别为求职准备，问出针对性问题，并输出含**简历优化建议 + 复习路线图 + 复习资料**的规划包
- [ ] 例 2（"我想转型，目标 AI 大模型应用"）能识别为技能转型，问出针对性问题，并输出含**学习路线图 + 学习资料 + 实战项目**的规划包
- [ ] 两个例子的输出结构按各自意图类型**显著不同**（而非同一模板换文案）
- [ ] 规划包为 HTML，双击可独立在浏览器打开，样式与内容完整，无外链依赖导致的空白
- [ ] 规划包内每一条资料都可以点击直达对应视频页或文档页
- [ ] 每条资料都标注难度、预计投入时长与"为什么学"
- [ ] 补充要求后能重新生成，且新结果体现该要求
- [ ] 关闭并重开 DSH 后，历史目标、画像与进度勾选均保留
- [ ] 生成的规划包文件出现在工作区，可从 DSH 文件树直接打开预览

## 与既有需求的关系

前两轮澄清中的「GitHub 高分项目浏览」与「多站点资源同步」**不废弃**，但角色从"终端功能"转为**支撑子系统**——它们构成真实资料池，供规划包生成时选取，从而避免模型编造不存在的链接。仍保留浏览入口，作为资料池的独立查看方式。
