# 资料池 · 需求文档（目标规划中心的支撑子系统）

> 依据：用户澄清（2026-09-16 第一、二轮）｜ 文档版本：v1.0 ｜ 状态：待确认决策点 R1–R4
> 关系：本文档是 `specs/features/目标规划中心.md` 的**支撑子系统**。资料池提供**真实、可验证**的资料与项目条目，供规划包生成时选取，从源头避免模型编造不存在的链接。

## 功能概述

**所属模块**：目标规划 → 资料池  **优先级**：P1

**一句话**：把散落在 GitHub 与各个学习站点的高质量资料，汇聚成一个可在 DSH 内浏览、检索、复用的资料池。

## 两个来源

### 来源 A｜GitHub 高分开源项目

- 按方向分类：通用大模型应用 / RAG / Agent 与工具调用 / 微调与训练 / 推理与部署 / 多模态 / 学习与教程
- 排序：星标数 / 最近更新
- 卡片信息：名称、简介、星标数、主要语言、项目图标
- 操作：点击跳转仓库；加入「我的清单」收藏
- 数据：**内置精选清单兜底**（断网也有内容）+ 一键实时刷新

### 来源 B｜多站点资源同步

按来源分类聚合，至少覆盖四类：

| 类别 | 候选来源 |
|------|----------|
| 论文与研究 | arXiv、Hugging Face Papers |
| 教程与文档 | OpenAI Cookbook、Hugging Face Learn、各框架官方文档 |
| 视频 | YouTube 频道、B站 |
| 中文社区 | 掘金、机器之心、InfoQ |

- 条目信息：标题、摘要、来源站点、发布时间、缩略图、可点击链接
- 操作：点击打开原文 / 直接播放视频；按来源筛选；关键词搜索；手动刷新同步
- 同步状态：显示「上次成功同步时间」；失败来源灰态并标注原因，其余来源照常显示

## 功能需求

### MVP 必需

- [ ] GitHub 高分项目浏览：分类 + 星标排序 + 关键词搜索 + 收藏
- [ ] 项目卡片可点击跳转仓库，含星标数、语言、图标
- [ ] 多站点资源流：至少 4 类来源，条目可点击打开
- [ ] 按来源筛选 + 关键词搜索
- [ ] 手动刷新同步 + 上次同步时间 + 失败友好提示
- [ ] **资料条目结构化**：类型、难度、预计投入时长、对应知识点、为什么学、建议顺序（供规划包直接引用）
- [ ] 本地缓存（避免频繁请求与限流）

### 后续迭代

- [ ] 自定义来源（用户粘贴 RSS / 站点地址）
- [ ] 关注点订阅：命中关注关键词时提示
- [ ] 失效链接检测与报告

## 边界条件

| 场景 | 处理方式 |
|------|----------|
| 首次打开、无任何数据 | 展示内置精选清单，并提示「点刷新获取最新」 |
| 拉取 GitHub 失败 / 超限 | 保留上次缓存 + 显示上次同步时间与失败原因，可重试 |
| 部分来源不可达 | 逐来源独立降级，失败来源灰态标注，其余照常显示 |
| 单来源条目过多 | 分页 / 懒加载，单来源上限 30 条 |
| 图片外链被环境拦截 | 降级为占位图标，不影响条目可点击 |
| 缓存数据损坏 | 回退为空并提示可重置 |

## 验收标准

- [ ] 断网时 GitHub 项目页仍有内置精选内容；联网刷新后呈现实时星标排序
- [ ] 资源流覆盖至少 4 类来源；任一来源失败不影响其余来源显示
- [ ] 所有条目链接可点击直达（或给出可复制链接）
- [ ] 每条资料条目具备难度、预计投入时长、为什么学三项结构化信息
