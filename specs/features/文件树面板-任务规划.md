### S1 沙箱保存授权流（扩展）

**背景**：保存工作区外文件报 `file access denied under workspace-write mode`。**白名单方案**（dsh-fs-sandbox rc.5+）：`SandboxedFileSystem.writeText` 第 5 参接受单次 `SandboxExecutionPolicy`，writableRoots = `policy.workspaceRoot` + tmp —— 把用户信任的文件夹作为本次调用的 workspaceRoot 传入，即按文件夹粒度放行（与命令白名单同语义），无需 `/permission` 开全部权限。旧运行时忽略该参则回退 /permission 重试流（客户端不绕过沙箱）。

| 编号 | 任务 | 产出 | 状态 |
|------|------|------|------|
| S1-1 | 保存结果信号 | saveFile 返回 `'saved'/'sandbox-denied'/'failed'`；识别 `FS_SANDBOX_DENIED` | ✅ |
| S1-2 | 信任目录持久化 | localStorage `dsk-develop-ui.trustedDirs`；trustDir/cancelSandboxApproval | ✅ |
| S1-3 | 授权面板 | WorkbenchEditor「保存需要授权」卡片；工作区外文件常驻 ⚠ 标记 | ✅ |
| S1-4 | 白名单直写 | client 已信任目录保存携带 `sandboxRoot`；host write-text 透传为单次策略（fs-service writeText 第 5 参，rc.7 类型未暴露故 cast） | ✅ |
| S1-5 | 旧运行时回退 | 白名单参数被忽略仍被拒 → 1.5s×40 重试 + /permission 引导 | ✅ |

### C5 终端面板（扩展 · v2 技术决策变更）

**需求（v2，用户变更）**：终端为**内嵌底部面板**——打开后默认在底部（sidebar 工作区列**独占从顶到底**，面板只占 sidebar 右侧区域）；支持**多个终端 tab**，关闭交互参考文件内容 Tab（✕ 右邻居激活、右键/⋯菜单 关闭当前/全部/左侧/右侧、最后 tab 关闭后面板隐藏）。

**形态决策（覆盖 v1 外置 OS 窗口方案）**：内嵌终端 = client 端 xterm.js 画布 + host 端 PTY 会话（node-pty 或等价）+ 双向流式通道。⚠️ 技术面大幅变化（原生模块打包、webServer 流式能力、沙箱对 PTY 的约束），**实现前需复审技术方案**（建议 `/feature-tech-design`）。

**安全约束**：shell 参数走 host 端硬编码白名单（powershell/pwsh/cmd/bash；~~wt~~ 是终端模拟器应用、无法嵌入 xterm，探针后移除——见 `docs/开发记录/C5-0-终端探针.md`）；cwd 经 `fs.resolve` + stat 校验（默认当前工作区路径）；路由与 write-text 同级（POST + `isLocalRequest`）。

| 编号 | 任务 | 产出 | 状态 |
|------|------|------|------|
| C5-0 | PTY 与流式通道探针 | node-pty 在 host 半可用性（原生模块打包/pnpm deploy）；`ctx.webServer` 是否支持 WebSocket/SSE/流式响应；DSH 沙箱对 PTY 进程的约束（被拦则评估官方 exec 通道或 `/permission` 引导，参照 S1） | ✅ 结论：可行，见 `docs/开发记录/C5-0-终端探针.md` |

### C6 文件内容区参考 VSCode 实现（重构 · 探针前置）

**需求**：文件内容列的展示/编辑形态对齐 VSCode（行号 gutter、当前行高亮、查找替换、多光标、括号匹配、可选 minimap），替换现有「透明 textarea 叠 shiki 层」自制编辑器。

**内核选型（C6-0 探针收口）**：A. monaco-editor（VSCode 同款内核，+3~4MB，语言服务 worker 未验证 → 退化主线程 monarch 高亮）／B. CodeMirror 6（+300~500KB，零 worker，80% 体验）／均受阻则 C（叠层手补行号，天花板低）。

> ✅ **探针结论（2026-08-25）：落 A（monaco-editor@0.52.2）**。报告：`docs/开发记录/C6-0-编辑器内核探针.md`。要点：minified 2657KB、无外链、codicon 字体内联、主线程 monarch 高亮、worker 走 MonacoEnvironment dummy stub、JSON 以 plaintext 兜底（无 monarch）。

**约束**：client 半单文件 bundle（编辑器内核与 CSS/字体必须打进 `lib/client.js`，复用现有 `.css: text` 内联注入模式）；`fileStore` 契约（content/dirty/selectedSnippet/saveFile/版本守卫/沙箱授权）不变；md 预览与图片预览路径不动。

## 5. 部署链路（每轮必走）

```
npm run build → pnpm pack →
rm -rf C:\Users\User\.dsh\profiles\desktop\node_modules\dsk-develop-ui →
pnpm -C "C:\Users\User\.dsh\profiles\desktop" install →
grep 标记验证安装副本 → 用户重启 DSH Desktop
```

> 同版本 file: tgz 必须先删 node_modules 目录，否则 pnpm 跳过（硬链）。
